# Скриншоты для README

Положи сюда 2–3 PNG (можно с телефона или Telegram Desktop):

| Файл | Что снять |
|------|-----------|
| `catalog.png` | Главное меню / список курсов |
| `course.png` | Карточка курса с кнопкой оплаты |
| `partner.png` | Личный кабинет партнёра (реферальная ссылка, бонусы) |

Рекомендуемая ширина: **1080–1920 px**. Не upscaling — только нативное разрешение.

После добавления файлов обнови секцию «Скриншоты» в корневом `README.md` (или попроси агента).
